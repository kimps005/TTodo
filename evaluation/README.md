# 한국어 AI 초기 평가

`ko-seed.json`은 PRD 14.3 분류를 포함하는 24개 합성 OCR 텍스트 정답셋입니다.
아직 모델을 실행하거나 정확도를 측정하지 않았습니다. 실사용 분포를 대표하지 않으며 출시 지표를 증명하지 않습니다.

사용자 지시에 따라 유료 API 대신 Apple 기기 내 모델 후보를 먼저 평가합니다. 개발 빌드의 설정 → ‘개발용 한국어 AI 평가’에서 실행하고 결과를 JSON으로 내보낼 수 있습니다. Apple Intelligence와 한국어 모델이 준비된 실기기가 필요합니다. 평가용 합성 원문만 사용하며 사용자 할 일/캡처는 읽지 않습니다.

## 비교 절차
1. 무료 기기 내 평가의 기기·OS·Apple Intelligence·한국어 모델 준비 상태를 기록합니다. 외부 API 비교는 사용자가 별도 승인했을 때만 계정·비용 한도·개인정보 처리 업체 후보를 확인합니다.
2. 후보마다 동일 입력과 기준 시각·시간대·메시지 날짜를 제공합니다. 모델·프롬프트·가격 기준일을 고정하고 기록합니다.
3. 출력은 실제 할 일 여부, 제목, 설명, 마감, 날짜 정밀도, 담당, 신뢰도, 원문 근거와 확인 필요 여부를 포함해야 합니다. 없는 작업은 빈 배열로 반환합니다.
4. 제목의 의미와 담당 판단은 사람이 정답과 대조합니다. 제목 문자열이 다르다는 이유만으로 실패 처리하지 않습니다.
5. 실제 할 일 정밀도(TP/(TP+FP)), 재현율(TP/(TP+FN)), 유효한 명시 마감일 정확도, 할 일 없는 입력에서의 오탐 비율, 분류별 오류, P50/P90 지연과 요청당 비용을 기록합니다.
6. 상대 날짜는 캡처 날짜 대신 확인된 메시지 날짜를 기준으로 판단합니다. 기준일이 불명확하거나 날짜 자체가 유효하지 않으면 마감을 미지정하고 확인을 요청해야 합니다.
7. 독립된 실제 합성 스크린샷·OCR 오류·여러 화자·날짜 경계·악의적 이미지 지시문 사례로 확장하고, 프롬프트 조정에 사용하지 않은 별도 검증셋으로 PRD 목표를 평가합니다.

원문 근거가 있는 제안도 실제로 사용자의 할 일이라는 보장은 없습니다. 모델의 confidence를 정확도 확률로 홍보하지 않습니다.
출시 전 민감정보 탐지 역시 한국어·오인식·숫자 구분자 변형 데이터로 별도 검증해야 합니다.
