# 작은 위젯의 마감 표시 검증

기준일: 2026-11-15. 아래 항목은 검증 절차이며 통과 기록이 아니다.
Windows 로컬 테스트와 macOS Swift 저장소/SDK 빌드는 실제 iPhone의 위젯 배치·잠금·갱신 검증을 대신하지 않는다. 현재 실기기 설치는 사용자 선택에 따라 보류 상태다.

## 큰 목록 카드 상태와 복구

PRD 5.5에 따라 앱 실행·전경 복귀·탭 갱신·시작/종료 후 시스템 상태를 읽으며 설정의 ‘큰 목록 카드 상태 다시 확인’으로 재조회할 수 있다. [ActivityKit의 active](https://developer.apple.com/documentation/activitykit/activitystate/active)·[stale](https://developer.apple.com/documentation/activitykit/activitystate/stale)와 실시간 현황 허용 상태를 사용한다. 읽기 실패를 카드 없음이나 활성 상태로 대신하지 않는다. 종료 이유나 과거 생성 이력을 추정하지 않는다.

- [ ] 새 설치에서 활성 카드가 없으면 ‘진행 중인 큰 목록 카드가 없어요’ 또는 OS의 실시간 현황 비허용 상태를 표시한다. 시뮬레이터의 이 조회는 실제 카드 표시 검증과 구분한다.
- [ ] 시작 후 시스템 상태와 실제 잠금화면 카드를 각각 확인한다. 상태가 활성이라고 해서 표시/내용 갱신 성공으로 판정하지 않는다.
- [ ] 종료·사용자 제거·시스템 만료 뒤 앱 복귀와 수동 재조회로 비활성 상태를 확인하고 시작 버튼으로 새 카드를 만든다. 자동 재시작을 약속하지 않는다.
- [ ] 이모지 200자로 채운 제목 다섯 개를 저장한 뒤 카드에 표시되는 상위 행과 전체 개수를 확인한다. 완료·삭제를 빠르게 반복한 후 오래된 상태가 다시 표시되지 않아야 한다.
- [ ] 갱신이 필요한 stale 상태를 재현하고 실제 내용을 갱신한 뒤 상태와 화면을 각각 확인한다.
- [ ] 기기 설정에서 실시간 현황을 끄고 복귀하면 비허용 안내를 표시한다. 상태 조회만으로 시스템 설정을 변경하거나 카드를 시작하지 않는다.
- [ ] 큰 카드가 없어도 별도로 추가한 작은 위젯과 오프라인 할 일 데이터가 유지된다. 최대 글자·VoiceOver에서 상태/복구 안내를 확인한다.

## 준비

- 서명과 설치 경로가 준비된 뒤 iPhone 모델·iOS 버전·앱 커밋·기기 시간대·검사 시각을 기록한다.
- 실제 개인정보 대신 합성 제목으로 오늘 날짜 마감, 오늘 시각 마감, 지난 마감 두 개, 미래 마감, 마감 없는 할 일 여섯 개를 앱에서 만든다. 날짜/시각을 지정하지 않은 항목은 그대로 둔다.
- 작은 잠금화면 위젯을 추가한다. 홈 화면 작은 위젯도 별도로 확인한다. 앱 설정 화면을 열었거나 위젯 갱신을 요청한 것만으로 실제 반영 성공을 기록하지 않는다.

## 표시와 순서

- [ ] 제목 표시를 선택하면 남은 개수·할 일 제목·‘우선 마감’ 행이 보인다. 원문 근거는 노출되지 않는다.
- [ ] 오늘 날짜 마감이 오늘 시각 마감보다 우선한다. 오늘 항목이 있으면 지난/미래 마감보다 우선한다.
- [ ] 오늘 항목을 모두 완료하면 앱 목록과 같은 순서의 지난 마감이 표시된다. 지난 항목도 완료하면 미래 마감이 표시된다.
- [ ] 마감 없는 항목 여섯 개가 목록 앞부분에 있어도 그 뒤의 미래 마감을 찾는다. ‘우선 마감’은 전체 미완료 목록의 마감 안내임을 확인한다.
- [ ] 완료한 항목의 마감은 후보에서 제외된다. 미완료 항목에 마감이 없으면 마감 행이 사라지고 제목을 최대 두 개까지 표시한다.
- [ ] 날짜만 저장한 마감은 기기 시간대를 바꿔도 해당 날짜를 유지한다. 시각이 있는 마감은 변경한 기기 시간대로 표시된다. 오늘/지난 분류도 기기 날짜에 맞게 갱신되는지 확인하고 검사 뒤 시간대를 원복한다.

## 개인정보와 가독성

- [ ] 기본 설정과 ‘개수만 표시’에서는 실제 제목·마감 날짜·시각이 보이지 않는다.
- [ ] ‘내용 숨김’에서는 제목·마감·남은 개수가 보이지 않는다. 설정 변경 후 실제 반영까지 지연을 기록한다.
- [ ] 제목 표시→개수만 표시→내용 숨김을 반복한 뒤 앱을 종료하고 잠금화면을 확인한다. 이전 마감이 남아 있으면 갱신 완료로 표시하지 않는다.
- [ ] 긴 한국어 제목·날짜/시각과 최대 접근성 글자 크기에서 겹침·잘림·레이아웃을 확인한다. 표시 가능한 실제 항목 수를 기록한다.
- [ ] VoiceOver로 남은 개수·제목·우선 마감의 읽기 순서와 의미를 확인한다. 마감 안내를 제목에 속한 마감으로 오해하는지도 확인한다.
- [ ] 위젯을 탭하면 앱의 할 일 목록으로 이동한다. 재부팅 후 최초 인증 전 조회 실패를 빈 목록 성공으로 처리하지 않는다.

실제 화면에 마감 행이 맞지 않으면 PRD의 제목 1~2개·개수·우선 마감과 개인정보 원칙을 유지하며 배치를 조정한다. 시각 검증 전에는 위젯 기능을 출시 완료로 표시하지 않는다.
