# TTodo 지원

## 할 일 기록하기

- **직접 입력** — 할 일을 추가하고, 제목이나 마감일을 수정하거나 완료·삭제할 수 있습니다. 인터넷 연결 없이 사용할 수 있습니다.
- **잠금화면에서 확인** — 잠금화면 위젯이나 목록 카드에서 할 일을 확인할 수 있습니다. 앱 설정에서 제목 표시, 개수만 표시, 내용 숨김을 선택할 수 있습니다.
- **이미지에서 할 일 찾기** — 분석에 동의한 후 앱에서 사진을 선택하거나 사진의 공유 메뉴에서 TTodo를 선택하세요. Apple Vision이 이미지 속 글자를 읽습니다. Apple 기기 내 모델을 사용할 수 있는 환경에서는 할 일과 마감일 후보를 검토하고, 필요한 항목만 골라 저장할 수 있습니다.

## Apple Intelligence와 기기 내 분석

자동으로 할 일 후보를 만드는 기능에는 Apple Intelligence를 지원하는 iPhone, 지원되는 iOS 및 기기 언어 환경, 그리고 활성화되어 사용할 준비가 된 Apple 기기 내 모델이 필요합니다. Apple Intelligence 지원 기기에서도 설정이나 모델 준비 상태에 따라 분석을 사용할 수 있는지가 달라집니다. TTodo의 최종 지원 기기·iOS·언어 범위는 실기기 검증 후 확정합니다.

기기 내 모델을 사용할 수 없으면 OCR에서 인식된 텍스트를 직접 선택해 할 일을 만들 수 있습니다. 직접 입력도 계속 사용할 수 있습니다.

## 잠금화면 빠른 입력 설정

1. TTodo를 한 번 열고 앱 설정의 **잠금화면 빠른 추가** 안내를 확인하세요.
2. iPhone의 **단축어** 앱에서 새 단축어를 만들고 **입력 요청**(Ask for Input) 동작을 추가하세요. 입력 유형은 텍스트로 설정하세요.
3. 이어서 TTodo의 할 일 추가 동작을 넣고, 할 일 텍스트에 앞 단계의 입력 결과를 연결하세요. 알아보기 쉬운 이름으로 단축어를 저장한 뒤 한 번 실행하고 TTodo 목록을 확인하세요.
4. 잠금화면을 길게 눌러 **사용자화**를 열고, 단축어 지정이 가능한 잠금화면 제어를 추가한 뒤 방금 만든 단축어를 선택하세요.
5. 잠금화면에서 제어를 눌러 짧은 테스트 할 일을 입력하세요. 완료한 뒤 TTodo 목록에 한 건이 저장됐는지 확인하세요.

제어 제공 여부와 입력 시 인증 요구는 iOS 버전과 기기 상태에 따라 달라질 수 있습니다. 인증이 요구되면 화면 안내를 따르거나 TTodo에서 직접 입력하세요. 인증 없이 입력하고 저장할 수 있는 조건은 실기기 검증 후 안내합니다.

## 자주 묻는 질문

### 스크린샷을 찍으면 바로 분석되나요?

자동 분석에는 사용자가 설정한 단축어 자동화가 필요합니다. iOS 27 이상은 우선 검증 대상으로, 촬영한 이미지가 앱에 정확히 전달되는지 실기기 확인이 남아 있습니다. 앱에서 사진을 선택하거나 사진의 공유 메뉴에서 TTodo를 여는 방식으로 이미지를 분석할 수 있습니다.

### 분석 알림을 받지 못했어요.

앱의 분석함에서 확인 대기 항목을 확인하세요. 알림이 꺼져 있어도 분석 결과는 앱에서 볼 수 있습니다. 앞으로 알림을 받으려면 iPhone 설정에서 TTodo의 알림 권한을 확인하세요.

### 제안이 틀렸거나 같은 이미지를 다시 분석하고 싶어요.

저장하기 전에 제목이나 마감일을 고치거나 필요 없는 제안을 무시할 수 있습니다. 아직 한 건도 저장한 적 없는 캡처만 다시 분석할 수 있습니다. 재분석으로 기존 미저장 제안을 교체하기 전에 확인 단계가 표시됩니다. 이미 저장한 항목은 할 일 목록에서 직접 수정하세요.

### 잠금화면 목록이 바로 바뀌지 않아요.

iOS에서 잠금화면 갱신을 처리하는 동안 지연이 생길 수 있습니다. 먼저 TTodo의 목록에서 저장 여부를 확인하세요. 큰 목록 카드가 만료되면 앱에서 상태를 확인하거나 작은 잠금화면 위젯을 사용하세요.

### 분석을 끄거나 데이터를 지우려면 어떻게 하나요?

TTodo 설정에서 분석 동의를 철회하거나 앱 데이터를 삭제할 수 있습니다. 할 일을 하나만 지우려면 해당 항목의 상세 화면에서 삭제하세요. 보존 및 삭제 범위는 [개인정보 처리방침](PRIVACY-POLICY.md)에서 확인할 수 있습니다.
