# 캡처 파이프라인 보강 검증

기준일: 2026-11-17. [PRD](PRD-v1.0.md), [출시 준비](MVP-READINESS.md), [기기 검증표](DEVICE-QA.md)의 제한을 유지한다. 아래 단위 검사를 실기기·실제 AI 정확도 측정으로 간주하지 않는다.

## 구현 정책

- Vision 좌표의 원점은 왼쪽 아래다. 텍스트 중심이 상단 6% 또는 하단 3%에 있으면 제외한다. 동일한 1% Y 구간은 X 순서, 완전히 같은 좌표는 인식 순서를 사용한다.
- 좌우 각각 두 개 이상, 왼쪽 시작/오른쪽 끝 X 편차 10% 이하, 세로 방향 교대 두 번 이상일 때만 `[상대방]`/`[나]`를 붙인다. 같은 행의 좌우 열은 표로 보고 태그를 붙이지 않는다. 이는 화자 추정 힌트이며 신원 보장이 아니다. 긴 말풍선·복잡한 문서·실제 메신저의 정밀도는 별도 평가한다.
- 프롬프트에 현재 기기 시간대의 날짜·시각·요일과, 사용자가 준 메시지 날짜의 요일을 넣는다. 현재 날짜와 촬영 날짜를 메시지 작성일로 대체하지 않는다. 기준일 없는 상대 날짜는 미확정으로 유지한다.
- `NSDataDetector`의 날짜 타입을 보조 검증에 사용한다. 현재 시각을 암묵적으로 참조하는 상대 날짜 탐지를 정답으로 쓰지 않는다. 원문에 연도가 명시된 날짜만 독립 대조하고, 내일/모레 및 이번·다음·지난 주의 요일은 명시된 메시지 날짜·시간대 기준으로 검산한다. 불일치하면 제목을 유지하고 마감을 비운다. 복수 날짜 문맥·한국어 파서 미인식은 실제 정확도 검증이 필요하다.
- 생성 결과는 배열을 유지한다. 무행동 안내·취소·일부 광고에 대한 좁은 규칙을 추가했으나 의미 판별을 정규식으로 보장하지 않는다. 풍경·밈·인사·단순 안내는 빈 배열을 반환하도록 지시한다.
- 모델 비활성·미지원·준비 중에는 OCR 줄을 검토용 초안으로 보관한다. 실행 도중 모델이 사용 불가로 바뀌어도 전환한다. 제목과 원문은 그대로 사용하며 날짜·담당을 추정하지 않는다. `vision-ocr/manual-v1`, 신뢰도 0, 확인 필요로 구분하고 기본 선택을 해제한다. 사용자가 글자를 선택·수정하고 저장 버튼을 누를 때만 할 일이 생긴다. 민감정보 차단·동의·보존/철회 정책은 유지한다.
- 단축어·공유 확장은 분석 UUID, 수신 시각, 시도별 `UUID-밀리초` 토큰으로 요청을 분리한다. DB의 `queued → processing → review/empty/failed`를 사용하고 프로세스 내 OCR/모델 연산은 FIFO로 실행한다. 프로세스 사이의 FIFO 순서는 보장하지 않으며 독립 토큰·트랜잭션으로 결과를 격리한다. 이미지를 공통 파일명으로 저장하지 않는다. 프로세스 종료 후 원본 복구는 하지 않고 기존 10분 중단 판정 뒤 명시적으로 다시 전달한다.
- 승인 시 SQLite 고유 출처 제약과 트랜잭션을 유지한다. 정규화한 제목·동일한 마감·설명이 같은 기존 항목은 생성을 거부한다. 명시한 담당이 서로 다른 항목은 구분한다. 수동 입력 중복 허용 정책은 유지한다. 유사 원문 경고도 계속 제공한다.
- 검토 화면의 마감 알림은 기본 꺼짐이다. 미래 날짜와 시각이 있을 때만 승인과 함께 `preferences`의 비내용 키 `todo_reminder.<할 일 UUID>`에 저장한다. 앱·확장은 같은 v3 스키마를 사용한다. OS 예약은 커밋 뒤 수행하며 실패·권한 거부를 저장 실패로 표시하지 않는다. 앱 목록 갱신 시 재시도하고, 완료·삭제·마감 변경·전체 삭제 때 현재 저장소와 예약을 대조한다. 알림에는 원문·제목을 표시하지 않는다. OS의 알림 개수·전달 지연·집중 모드 제한은 실제 기기에서 확인한다.

## 자동 검사

- JS: `npm run typecheck`, `npm test`.
- macOS 품질 workflow: 기존 Swift 저장소·캡처·JSON 계약, 실제 합성 한국어 Vision OCR, `PipelineSmoke.swift`, 앱·위젯·공유 확장 시뮬레이터 빌드.
- 새 Swift 검사: 상태바/홈 제외, 줄 순서, 좌우 대화와 표 구분, 요일·시간대, 상대 날짜 불일치, 날짜 탐지 API 실행, 빈 결과/무행동 필터, 실행 도중 모델 비활성 전환, 대기 요청 격리, OCR 미선택, 승인 중복·기존 중복, 알림 계획, 오래된 큐 토큰 거절.

## 실제 iPhone에서 남은 검사

- [ ] 상태바·홈 경계, 가로/세로·긴 캡처, 키보드가 보이는 메신저, 표·여러 열·긴 말풍선에서 실제 OCR 손실과 화자 오류 측정.
- [ ] iPhone 16 Pro에서 실제 `SystemLanguageModel.default`의 한국어 정밀도·마감 정확도·지연 측정. 풍경·밈·안내문에서 빈 배열 확인. [평가 절차](../evaluation/README.md)를 따른다.
- [ ] AI 꺼짐·모델 다운로드 중·지원 불가 상태에서 앱/공유창/단축어 OCR 초안 선택→제목/날짜 수정→다중 승인. 선택·저장 전 할 일 0개 확인.
- [ ] 단축어와 공유창의 연속 서로 다른 캡처, 같은 캡처 중복, 처리 중 취소·강제 종료·동의 철회와 재동의. 원문·지문·제안 ID·승인 출처가 섞이지 않아야 한다.
- [ ] 승인 알림 켜기/끄기, 미래 날짜·시각 누락, 알림 권한 거부/복구, 앱 복귀 재예약, 완료·삭제·전체 삭제 후 예약 취소. VoiceOver·Dynamic Type에서도 선택/알림 상태가 전달되어야 한다.

서명·설치 보류 선택을 유지한다. 위 체크는 모두 미검증이다.
