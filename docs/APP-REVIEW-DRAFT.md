# 심사 재현 안내 초안

기준일: 2026-11-15. PRD 17.3의 심사 재현 자료를 준비하는 개발 문서다.
현재 앱은 제출 가능한 상태가 아니며 이 문서를 App Store Connect에 등록하지 않았다.
실제 서명 빌드·기기·검증 결과가 확정되면 해당 버전에 맞춰 다시 작성한다.

## 제출 전에 확정할 정보

- 제출할 버전/빌드/커밋, 최종 Bundle ID와 App Group, 실제 서명 설치 경로.
- 공개 운영자 이름/상호, 지원 이메일, 공개 개인정보 처리방침/지원 URL. 현재 미정이며 임의의 연락처나 URL을 넣지 않는다.
- 템플릿을 교체한 최종 앱 아이콘과 실제 제출 빌드의 iPhone 화면.
- 지원 기기/OS의 실제 AI 결과·한국어 정확도와 잠금 입력·캡처 자동화의 출시 차단 검증. CI 컴파일이나 합성 응답으로 대체하지 않는다.

## 계정 없이 수동 입력 시험

1. 앱을 새로 실행하고 온보딩의 ‘이 설정으로 시작하기’를 누른다. AI 동의와 알림 허용 없이 진행할 수 있다.
2. ‘새 할 일’에 합성 제목을 입력하고 ‘할 일 추가’를 누른다. 항목을 열어 제목·설명·마감을 편집한다. 날짜만 입력한 경우 시각을 임의로 붙이지 않는다.
3. 완료/미완료 전환, 앱 재실행 후 보존, 삭제 취소/삭제를 확인한다. 수동 입력은 네트워크 API를 호출하지 않는 로컬 저장 경로다. 실제 기기의 네트워크 차단 시험은 별도로 기록한다.
4. 설정에서 알림을 거부해도 저장한 할 일에 접근할 수 있어야 한다. ‘알림 설정 열기’는 OS의 TTodo 알림 설정을 연다. 실제 이동·복귀 결과는 STATUS.md의 해당 UI 실행 범위를 따른다.

## 직접 선택한 사진과 AI 제안 시험

1. 개인정보가 없는 한국어 안내 이미지를 사용한다. 예: ‘2026년 11월 20일까지 보고서 제출’. ‘분석함’ → ‘캡처에서 할 일 찾기’ → ‘사진에서 선택’으로 이미지를 직접 선택한다.
2. 실제 인식된 글자를 확인하고 필요하면 수정한다. 날짜 문맥이 필요하면 ‘원문 메시지 기준 날짜 YYYY-MM-DD’를 직접 입력한다. 이미지 촬영 날짜를 대화의 기준일로 임의 사용하지 않는다.
3. 기기 내 모델의 사용 가능 상태를 확인한다. 구현은 iOS 26 이상에서 기기 적합성·Apple Intelligence 설정·모델 준비 상태를 확인한다. 이 조건은 한국어 정확도나 정식 지원 확정을 뜻하지 않는다. 미지원 상태에는 합성 제안을 실제 AI 결과처럼 표시하거나 유료 API로 전환하지 않는다.
4. 동의 후 ‘기기 내 AI로 할 일 찾기’를 실행한다. 검토 화면에서 제목·날짜·원문 근거를 확인하고 선택한 항목만 저장한다. 승인 전 제안은 할 일이 아니다. 실제 모델 실행과 결과 품질은 현재 미검증이다.
5. 같은 이미지 재분석은 한 번도 저장하지 않은 캡처에만 허용한다. 미저장 제안 교체는 확인창을 거치며, 한 항목이라도 저장한 이력이 있으면 이후 삭제 여부와 관계없이 차단한다.

## 단축어·공유·위젯 시험

- 단축어 수동 입력: ‘입력 요청’의 결과를 ‘TTodo에 할 일 추가’의 ‘할 일’ 값에 연결한다. 앱을 열지 않는 의도와 인증 정책을 코드에 선언했지만 잠금 상태의 인증 없는 실제 입력 성공은 미검증이다.
- 단축어 캡처 분석: 선택한 이미지 파일을 ‘TTodo에서 캡처 분석’의 ‘분석할 이미지’에 직접 전달한다. 최신 사진을 임의 검색하지 않는다. 스크린샷 자동화 트리거·파일 전달·잠금/종료 실행은 기기 검증 전이며 모든 OS에서 자동 지원한다고 안내하지 않는다.
- 공유 메뉴: 이미지 한 장을 TTodo 공유 확장에 전달한다. 동의 전에는 분석하지 않아야 한다. 실제 시스템 공유창의 동의 차단 CI와 실제 기기 내 AI 실행·저장은 다른 검증이다.
- 위젯: 작은 잠금화면/홈 위젯을 직접 추가한다. 기본값은 개수만 표시다. 설정에서 제목 표시를 선택한 경우에만 제목·우선 마감을 노출한다. 큰 목록 카드는 OS에 의해 만료될 수 있다. 실제 배치·갱신·잠금·VoiceOver는 [위젯 검증표](WIDGET-QA.md)를 따른다.

## 데이터 처리 확인

- 외부 AI 서버로 이미지/글자를 전송하지 않는다. 실제 네트워크 검증과 App Store 개인정보 응답은 별도 출시 항목이다.
- 원본 이미지는 영구 보관하지 않고 앱 임시 파일은 화면 종료 또는 다음 실행 때 정리한다. 동의한 원문 근거는 7일이 지나면 다음 앱 실행/확인 때 정리하며 정확한 시각에 백그라운드 삭제를 보장하지 않는다.
- ‘AI 중지 및 원문 근거 삭제’, 개별 할 일 삭제, ‘모든 데이터 삭제’의 범위는 [데이터 생명주기](DATA-LIFECYCLE.md)를 따른다. 개별 할 일 삭제는 연결된 제안 본문을 지우고 다른 할 일/제안은 유지한다.
- 전체 데이터 삭제가 OS 알림 권한까지 초기화하는 것은 아니다. 개인정보 선언 수집 결과는 [PRIVACY-MANIFESTS.md](PRIVACY-MANIFESTS.md), 실제 통과 범위와 남은 차단 항목은 [STATUS.md](STATUS.md)를 확인한다.
