# MVP 구현과 남은 출시 검증

기준일: 2026-11-17. 제품 기준은 [PRD](PRD-v1.0.md)다. 아래의 코드 구현이나 CI 통과는 PRD 21의 출시 완료 판정이 아니다. 실제 iPhone 설치는 사용자 선택에 따라 보류하고 Windows 개발과 GitHub macOS CI를 유지한다.

## 최신 코드 검증

최신 품질 검사 대상은 `42cce33`다. [전체 품질 CI](https://github.com/kimps005/TTodo/actions/runs/44030805582)에서 130개 JS 테스트·타입·보안 취약점 0·Hermes, 실제 Swift 저장소/캡처와 JSON 계약, 합성 Vision OCR, 앱·위젯·공유 확장 시뮬레이터 빌드와 개인정보 선언 12개 수집이 통과했다. 완료 목록 마감/AI 출처·연도 표시, 검토 마감 수정 요약, 큰 목록 카드의 시스템 상태 조회를 포함한다. 같은 소스의 [서명 없는 Release 아카이브](https://github.com/kimps005/TTodo/actions/runs/44030964495)도 Xcode 26.6 / iPhoneOS SDK 26.5에서 성공했다. arm64 실행 파일·위젯/공유 확장 포함 검사·Info.plist 검증·개인정보 선언 12개 수집을 확인했다. [세 환경 UI](https://github.com/kimps005/TTodo/actions/runs/44030805430)는 iOS 26.2 수동 수명주기만 통과했고 최신 iOS 시작 대기·작은 화면 설정 제목 탐색은 실패했다. 탭 스크롤 분리와 시작 단계 진단은 후속 검증 전이며 STATUS 참조. 설치용 서명·실제 iPhone·AI 정확도 검증은 아니다.

각 UI 성공은 해당 커밋·시뮬레이터·검사에 한정된다. 이후 제품 변경에 자동으로 승계하지 않는다. 실행 링크와 실패·제한은 [STATUS](STATUS.md), 절차는 [CI 검증](CI-VALIDATION.md)과 [실기기 검증표](DEVICE-QA.md)에 기록한다.

알림 설정 화면 이동은 공개 API 호출 뒤에도 시뮬레이터가 해당 목적지를 표시하지 않은 미해결 제약이 있다. [조사 기록](NOTIFICATION-SETTINGS-INVESTIGATION.md)을 유지하며, 사용자가 보류한 같은 진단을 임의로 반복하지 않는다. 사진 UI의 이전 성공과 후속 시뮬레이터 사진 가져오기 준비 실패도 별개 결과로 기록한다.

## 현재 실행할 수 없는 필수 검증

- 실제 iPhone용 서명·설치 경로가 없어 잠금 입력·App Group 보호·자동화·위젯·VoiceOver의 기기 판정은 보류한다. 사용자가 선택한 설치 보류 방침을 유지하며 AltStore·유료 가입·Mac 대여를 진행하지 않는다.
- CI 호스트에서 실제 기기 내 모델이 사용 가능하지 않았으므로 모델 정확도 수치를 만들지 않는다. 실제 기기에서 합성 평가 입력을 실행한 결과와 사람의 의미/마감 판정이 필요하다. [평가 절차](../evaluation/README.md)를 따른다.
- 알림 설정 목적지가 시뮬레이터에서 숨겨지는 문제는 독립 네이티브 비교에서도 재현되었다. 임의 URL 우회나 반복 재검사를 진행하지 않으며 [조사 기록](NOTIFICATION-SETTINGS-INVESTIGATION.md)의 제한을 유지한다.

## 공개 배포 준비와 구분

운영자 이름/상호·지원 이메일은 미정이다. 최종 공개 정책/지원 URL, 분석 오류 신고의 실제 지원 접수 경로와 App Store 등록은 해당 정보 확정 후 진행한다. 개발용 데이터 처리 문서를 공개 정책으로 대신하지 않는다. 최종 아이콘·제출 화면·TestFlight·App Store 심사도 남아 있다. 기존 Expo 템플릿 자산이나 서명 없는 아카이브를 제출 준비 완료로 표시하지 않는다.

현재 네이티브 검증은 시뮬레이터 빌드와 서명 없는 iPhoneOS Release 아카이브다. 계정 프로비저닝·설치·App Store 배포를 검증한 결과가 아니다.
